Konfigurasi Aplikasi

Koneksi Google Apps Script

URL backend sudah ditetapkan agar komputer dan HP memakai server yang sama. Jika deployment berubah, perbarui URL di sini dan simpan. Jangan gunakan data pasien pada konfigurasi publik.

Catatan deployment

  1. Upload index.html dan kedua logo ke repository GitHub.
  2. Deploy Google Apps Script sebagai Web App dan siapkan fungsi POST/GET sesuai protokol aplikasi.
  3. Masukkan URL /exec di bagian ini.
  4. Uji simpan dan baca data dengan data dummy sebelum digunakan operasional.

Jangan memasukkan kredensial rahasia ke HTML publik. Atur autentikasi dan akses Google Drive/Sheets secara terbatas.
